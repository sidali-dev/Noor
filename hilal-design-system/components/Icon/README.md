# Icon

The system's 24px line-icon set, drawn inline so it takes the surrounding text colour.

**Consumer provides:** `name` (one of `home`, `compass`, `calendar`, `bookmark`, `settings`, `moon`, `star`, `search`, `bell`, `check`, `alert`, `plus`; the list is `Hilal.Icon.names`), optional `size` (px, default 24), `strokeWidth` (default 1.6), and `label` (only when the icon stands alone and means something).

- Round caps and joins, 1.6 stroke at 24px — thin like cut paper edges. Don't mix with filled icon sets.
- Colour comes from CSS `color`: `ink` on paper, `on-window` on night.
- An icon next to a word needs no label; an icon-only button needs one.
