# Motifs

Original cut-paper shapes for illustrations, splash art and empty states. In product UI, prefer the `ArchFrame` and `Ornament` components, which draw these in live tokens; use the files where a component can't go (marketing images, app-store art, native code).

- `arch-window.svg` — the scalloped pointed arch, 200×240 (5:6). Ink: `window` (#171a21). Use it as a mask or clip shape for photos and panels; place a white `surface-raised` copy behind it, scaled about 7% larger, for the paper frame.
- `crescent.svg` — the crescent moon. Ink: `window` (#171a21) as shipped; recolor to `on-window` (#f7f7f4) when placing on night.
- `star-8.svg` — the eight-point star (two overlaid squares). Ink: `brass` (#7a6436). Ornament only, small: 12–16px in UI.
- `cloud-scroll.svg` — the paper cloud bank that hides the base of an arch. Inks: `surface-raised` (#ffffff) front, `surface-sunken` (#e3e6ec) back row, `line` (#cfd3dc) swirls. Paper theme only as shipped; on Night, recolor to #1c1f27 / #0a0b0f / #2c303a.
